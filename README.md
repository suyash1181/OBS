# Orbital Strike Cannon MK3 — Project Showcase

A responsive, static landing page for the Orbital Strike Cannon MK3 Minecraft engineering project.

## Preview locally
Open `index.html` in a browser. The site uses plain HTML and CSS; no build step, JavaScript package, or external asset is required.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. The included workflow deploys the site whenever a commit is pushed to the default branch.
4. When the workflow completes, the Pages URL appears in **Settings → Pages**.

## Customize
- Edit `index.html` to change the project description, feature cards, and colors.
- Replace the abstract CSS hero graphic with your own screenshots when ready.
- Keep screenshots and any other static assets in a folder such as `assets/`, then link them with relative paths.

This is a presentation site and project log, not an executable mod or command implementation guide.
